# AI, Actually

A static editorial prototype: a weekly roundup and an occasional evidence-led explainer.

## Preview

Run `python3 -m http.server 4317 --directory dist` from this directory and open http://localhost:4317.

## Editing

The authored site lives in `dist/index.html`, `dist/data-centers.html`, and `dist/styles.css`. No build dependencies are required. Update the edition dates and source links together. The first edition covers September 7-13, 2026. Both roundup stories are first-party MIT reporting and are labeled accordingly.

## Scope

Two sourced roundup stories, a short data-center explainer, responsive reading layouts, native source disclosures and print styling. No subscription collection or email delivery is connected. Audience testing remains outstanding.
